# Fastlane MCP — دليل الربط والاختبار

> الحالة: مسودة إجراء تشغيلي.
>
> الوصول المباشر إلى
> `api.usefastlane.ai`
> و
> `developers.usefastlane.ai`
> محجوب بسياسة الشبكة في بيئة التنفيذ، فلم يُنفَّذ أي استدعاء حي. ما تحقق منه
> أدناه جاء عبر البحث في الوثائق المنشورة فقط، وما بقي مجهولًا موسوم صراحة في
> قسم «ما لم يُتحقق منه».

## 1. المبدأ

الربط يتم على ثلاث مراحل، ولا ننتقل لمرحلة قبل نجاح ما قبلها:

| المرحلة | الصلاحية | الهدف |
|---|---|---|
| A | قراءة فقط
(read-only) | إثبات أن الحساب المجاني يسمح بالـ MCP |
| B | إنشاء مسودات
(draft) | توليد محتوى دون نشر |
| C | جدولة ونشر
(schedule / publish) | بعد مراجعة بشرية صريحة |

لا تُمنح صلاحية النشر التلقائي للوكيل في المرحلة الأولى.

## 2. ما تأكد من الوثائق المنشورة

- واجهة
  Fastlane
  هي
  REST
  فوق
  HTTPS
  بصيغة
  JSON،
  مخصصة للاستخدام من خادم إلى خادم.
- كل طلب يتطلب مفتاحًا يُنشَأ من إعدادات مساحة العمل.
- المسار محكوم بإصدار في العنوان:
  `/api/v1`
  والتغييرات الكاسرة تصدر تحت إصدار رئيسي جديد.
- خادم
  MCP
  يعرض **نفس** الواجهة لعملاء مثل
  Claude
  بنفس المفتاح ونفس مساحة العمل، دون تهيئة إضافية.
- استدعاءات إنشاء المحتوى تُخصم من رصيد الحفظ الشهري، وعند نفاده يعود الرد
  `content_quota_exceeded`
  ما لم تُفعّل فوترة التجاوز من
  `Settings → API`.
- الجدولة والنشر عبر مفاتيح مساحة العمل العادية غير محسوبة ضمن هذا الاستهلاك.

## 3. ما لم يُتحقق منه

هذه النقاط مبنية على مصدر غير رسمي وتحتاج تأكيدًا من شاشة
`Settings → API`
في حسابك:

| البند | القيمة المفترضة | الحالة |
|---|---|---|
| مسار MCP | `https://api.usefastlane.ai/mcp` | غير مؤكد |
| بادئة المفتاح | `fsln_live_` | غير مؤكدة |
| اسم الترويسة | `Authorization: Bearer` | غير مؤكد |
| هل الخطة المجانية تشمل إنشاء مفتاح API | — | **غير محسوم** |

الخطة المجانية
(Basic)
قائمة فعلًا وتشمل توليدًا وجدولة محدودَين، لكن لا يوجد نص منشور يحسم أن إنشاء
مفتاح
API
متاح فيها. لا تشترِ خطة بناءً على افتراض؛ اختبر أولًا.

### كيف تُحسم هذه النقاط بأمر واحد

في المستودع سكربت فحص جاهز:
`scripts/fastlane-mcp-probe.sh`

يُشغَّل من جهاز لديه وصول شبكي إلى
Fastlane،
ويجرّب المسارات المرشّحة وصيغ الترويسة الثلاث، ثم يطبع جدولًا يحدد أيها يعمل:

```bash
export FASTLANE_API_KEY='fsln_...'
./scripts/fastlane-mcp-probe.sh
```

الضمانات المهمة في السكربت:

- يقرأ المفتاح من متغير بيئة فقط، ولا يطبعه ولا يكتبه في أي ملف.
- يرسل مصافحة
  `initialize`
  فقط، أي قراءة محضة؛ لا يُنشئ محتوى ولا يجدول ولا ينشر.
- كل القيم قابلة للتجاوز
  (`FASTLANE_BASE`،
  `FASTLANE_PATHS`،
  `FASTLANE_HEADERS`،
  `FASTLANE_TIMEOUT`)
  فلا شيء مثبّت بالقوة.

قراءة الجدول:

| النتيجة | المعنى |
|---|---|
| `200` أو `202` في صف واحد | هذا هو المسار وصيغة الترويسة الصحيحان |
| `401` في كل الصفوف | المفتاح خاطئ أو لا ترويسة من الثلاث صحيحة |
| `403` في كل الصفوف | المفتاح سليم لكن الخطة لا تمنح وصول API/MCP |
| `404` أو `405` في كل الصفوف | المسار مختلف؛ خُذه من `Settings → API` |
| `conn-fail` | الشبكة منعت الاتصال، والمشكلة ليست من Fastlane |

أرسِل الجدول — لا المفتاح — وتُستكمل الوثيقة على أساسه.

### إن أردت تنفيذ الفحص من بيئة التنفيذ السحابية

سياسة الشبكة في البيئة الحالية ترفض المضيف
`api.usefastlane.ai`.
لتمكينه يُعدّل
Network access
من إعدادات البيئة
(Edit)
إما بمستوى وصول أوسع أو بخيار
Custom
مع إضافة المضيف إلى
Allowed domains
والإبقاء على القائمة الافتراضية لمديري الحزم. الخطوات في:
`https://code.claude.com/docs/en/cloud-environments#network-access`

## 4. المتطلبات

1. حساب Fastlane فعّال.
2. مفتاح API من:
   `Settings → API`
   وصيغته المتوقعة تبدأ بـ
   `fsln_live_`
3. عميل يدعم
   MCP
   مثل
   Claude Code

المفتاح يُعرض مرة واحدة فقط عند الإنشاء. احفظه في مدير أسرار، ولا تضعه في المستودع.

## 5. الإعداد

ضع المفتاح في متغير بيئة بدل كتابته داخل الملف:

```bash
export FASTLANE_API_KEY="fsln_live_..."
```

ثم أضف الخادم إلى إعداد
MCP
المحلي (مثال `.mcp.json` في جذر المشروع، أو إعداد المستخدم):

```json
{
  "mcpServers": {
    "fastlane": {
      "type": "http",
      "url": "https://api.usefastlane.ai/mcp",
      "headers": {
        "Authorization": "Bearer ${FASTLANE_API_KEY}"
      }
    }
  }
}
```

ملاحظات مرنة:

- إذا رفض الخادم ترويسة
  `Authorization`
  فجرّب
  `X-API-Key`
  حسب ما تعرضه صفحة التوثيق داخل حسابك.
- إذا كان الربط عبر
  OAuth
  بدل المفتاح، احذف كتلة `headers` ونفّذ تفويض المتصفح من جلسة تفاعلية.
- قيمة `type` قد تكون `http` أو `sse` حسب إصدار العميل.

## 6. اختبار المرحلة A (قراءة فقط)

1. أعد تشغيل العميل ثم تحقق من ظهور الخادم في `/mcp`.
2. اطلب أولًا سرد الأدوات المتاحة دون تنفيذ أي منها.
3. نفّذ استدعاءً واحدًا للقراءة فقط، مثل عرض
   Content
   أو
   Preferences
   الخاصة بمساحة العمل.
4. معيار النجاح: ظهور بيانات
   Workspace
   الحقيقية. أي استجابة فارغة أو
   `403`
   تعني أن الخطة لا تشمل
   MCP
   أو أن المفتاح غير مفعّل.

## 7. معالجة الحالات المتوقعة

| العَرَض | التفسير المرجّح | الإجراء |
|---|---|---|
| `401` | مفتاح خاطئ أو ترويسة غير صحيحة | جرّب صيغة الترويسة البديلة |
| `403` | الخطة لا تشمل MCP | وثّق الرد وارجع لصفحة التسعير قبل أي دفع |
| `404` على المسار | المسار مختلف في حسابك | خذ المسار من صفحة API داخل الحساب |
| لا يظهر خيار API أصلًا | الميزة غير مفعّلة للحساب | لا تشترِ قبل تأكيد الدعم |

## 8. حدود هذه الوثيقة

- لم يُختبر أي استدعاء فعلي من هنا؛ الشبكة تمنع المضيف.
- صلاحيات الخطة المجانية تُثبت بالتجربة لا بصفحة التسويق.
- المرجع الرسمي للتفاصيل الدقيقة:
  `https://developers.usefastlane.ai`
- لا تُمنح صلاحيات الكتابة إلا بعد نجاح المرحلة A وتوثيق نتيجتها.
